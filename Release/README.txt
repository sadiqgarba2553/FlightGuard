FLIGHTGUARD 0.5 - WINDOWS x64
Created for Infinite Flight Community member sadiq_ibraheem.

Close older FlightGuard copies. Run FlightGuard.exe; open START-HERE.html.
Same Wi-Fi: start a flight, enable Infinite Flight Connect and use Discover
or your device's local IP. No cloud API key or Windows speech is used.

GATE TO GATE
Flight tools > Cabin: parked brake-set boarding begins after 3 seconds.
Welcome/boarding ambience, boarding-complete effect, safety briefing, taxi
rolling ambience, cabin-ready calls, descent/landing preparation, taxi-in
and parked arrival/deboarding are scheduled from observed flight history.
Use Start new boarding leg or Boarding complete / pushback as needed.
These controls only schedule audio. Tug, passenger, door and runway status
are not inferred. Joining in the air skips boarding. GA requires opt-in.

Cabin volume is separate. GPWS and cockpit calls interrupt cabin audio.
Cabin stays quiet during takeoff/go-around and below 1,500 ft airborne.
Interrupted or obsolete announcements are not resumed. Stop cabin audio
preserves GPWS. Enable it and Apply again to resume.

FLIGHT TOOLS
Separate aircraft preferences; local JSONL recording and isolated replay;
configurable approach monitor; estimated landing reports; verified pack
download/repair; automatic spoiler deployment and deceleration calls.
Verify and arm V-speeds each flight. Set approach target speed and minimum
landing flap STATE (index, not degrees). Target 0 disables speed monitoring.

AUDIO
195 WAV mappings; 12 repair/download packs with 194 original clips.
Shared FlyByWire cabin recordings may include original aircraft/airline
wording. Exact OEM sets for all aircraft remain incomplete. Windshear and
spoken go-around clips are missing. No fabricated speech substitutes.

TIMING
Polling target 50 ms. Live ground check on 777-200ER: 12 samples averaging
52.59 ms (~19 Hz). Not a full-flight timing test. 109 logic checks, 195 audio
decodes, actual 11-clip cabin installer download and 903-frame isolated
replay passed. Detailed reports: Validation/. Native submission timing
is not acoustic latency and Wi-Fi/audio-device delays still apply.

FILES AND LICENCES
Data contains settings, aircraft profiles, local recordings, landing reports
and pack backups. Keep the folder writable; no telemetry is uploaded.
Replay limits: 300 MB, 500,000 frames, 1,000,000 events per file.
